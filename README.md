# The Copper Bean — Coffee House & Roastery

A premium, responsive 5-page demo website for a specialty coffee house & micro-roastery.
Built as a static site (HTML / CSS / vanilla JS) with a coffee-toned palette and minimal,
GPU-friendly animations that run well on low-end devices.

## Pages
- `index.html` — Home (hero, signatures, reviews, footer)
- `menu.html` — Menu (category + sub-category tabs, featured items)
- `about.html` — About (story, ambience, values, timeline, team)
- `gallery.html` — Gallery (masonry grid + lightbox)
- `contact.html` — Contact (details, hours, map, form)

## Structure
- `css/style.css` — shared design system & responsive styles
- `js/main.js` — intro loader, nav, scroll reveal, menu tabs, lightbox

## Run locally
```bash
python3 -m http.server 8787
# then open http://localhost:8787/index.html
```

> Demo content — all names, reviews, photos (Unsplash) and contact details are fictional.
